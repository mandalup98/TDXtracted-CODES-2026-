# Looking through TDX

This repository contains the accompanying code for "Looking through TDX: Guest Execution Characterization of ML workloads via Performance Counters" submitted at NDSS, 2026.

## Directory Structure

1. **`Establishing Leakage`**: Contains all the codes and data needed to establish the leakage 

2. **`Systematic Analysis and Process Identification`** Contains all the codes and data needed for analysis of all the PMC events and also code for process identification. 
   
3. **`Lelage of Model Architecture`**: Contains all the codes and data needed for leakage of Model Architecture. 

4. **`Class Leakage Attack`**: Contains all the codes and data needed for performing the Class Leakage Attack.
